## 问题

`CLAUDE.md` 写：加价策略 5 种（`flat_pct` / `per_item_pct` / `per_item_fixed` / `category_pct` / `stepped`），
「前端只暴露前 3 种，**4/5 通过 `markup-rules` API 用模板使用**」。

**但那四个 action（`list` / `create` / `update` / `deleteMarkupRule`）前端零调用。**

所以「通过 API 用模板」这句话不成立——**`category_pct`（按品类）和 `stepped`（阶梯）事实上不可用。**
