## 背景

`6a1dfb0`「改用斑兔企服版式」重构了两个打印页，但**各写了一套 CSS**：
- 报价单 `QuotePrint.tsx` → `q-*` 类名体系（q-head/q-meta/q-table/q-sum/q-grand/q-foot…）
- 发票 `InvoicePrint.tsx` → `i-*` 类名体系

之后 `163a092` 又只改了报价单（去「此致」落款），两页差距进一步拉大。

老板 08-11 验收 07 号单时反馈：**发票的字体、样式有问题，参考报价单调整。**

## 怎么做

**以报价单（`q-*`）为基准，把发票的字体/字号/间距/对齐向它看齐。** 不必强行合并成一套类名
（那样改动面大、风险高），但视觉规格要一致：

- [ ] 字体族、字号档位（标题/表头/正文/辅助）对齐 q-*
- [ ] logo 与公司名间距、抬头区排布对齐
- [ ] 表格：列对齐规则（数字右对齐 tabular-nums、居中列）、行高、边框对齐 q-table
- [ ] 合计区（i-totals / i-grand）视觉对齐 q-sum / q-grand
- [ ] 页脚三栏（i-foot）对齐 q-foot
- [ ] 三语切换下都不撑破（印尼文最长）

## 🔴 正确姿势（踩过的坑，别盲改）

本机无登录态、CSS 内联在 tsx 的模板串里。**必须**：
1. 把 `InvoicePrint.tsx` 和 `QuotePrint.tsx` 的 style 串抽成 css 文件 + 静态 mock html
2. headless Chrome 截图对比，在 scratchpad 里迭代到两页视觉一致
3. 再回写 tsx，`npm run build` 提交 dist

**不要直接改 tsx 里的 CSS 值靠想象**——报价单/发票的排版问题历史上都是这么被截图暴露的。
