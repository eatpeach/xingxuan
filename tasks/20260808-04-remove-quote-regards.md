## 背景

对客报价单（`/quotes/:id/print`）右下角有个落款块：

```
                                        此致
                                ──────────────
                                        星选建材
```

**这行中文是错的。**「此致」是书信格式，完整写法是「此致敬礼」，单独挂在公司名上面语法不成立，中文报价单不这么写。它是照着英文 `BEST REGARDS` 直译来的——英文 `BEST REGARDS`、印尼文 `HORMAT KAMI` 在商务文件里都成立，唯独中文这条不成立。

### 它是怎么来的（不是「删了又冒出来」）

用户问「为啥报价单里还有此致」，是因为 5 月删过一次落款。查了下，那次删的和现在这个不是一个东西：

| 时间 | 提交 | 干了什么 |
|---|---|---|
| 2026-05-08 | `a09da0d` | 删掉**旧的签字盖章块**（客户确认签字 / 公司盖章 / 日期），与现在这块无关 |
| 2026-08-06 | `184e495` | 新建 `printI18n.ts` 做三语切换，定义 `regards: 此致 / BEST REGARDS / HORMAT KAMI`，当时**只用在发票**落款 |
| 2026-08-07 | `6551e41` | 「报价单/发票改用参考版式重构」——照参考版式**给报价单新加了落款块**，复用了发票的 `regards` |
| 最新 | `6a1dfb0` | 只把 class 从 `doc-sign` 改名 `q-sign`，块原样保留 |

## 决策（CTO，2026-08-08）

**报价单的落款块整个删掉。** 不改文案，不换成「顺颂商祺」——报价单底部已有页脚（品牌条 + 公司名 + 电话），落款是冗余。

**发票（`InvoicePrint.tsx`）的落款不动。** 发票上的 `HORMAT KAMI` 是印尼商务惯例，落款场景与报价单不同，是否调整另行决策。
